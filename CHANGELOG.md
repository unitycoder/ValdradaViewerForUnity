# Changelog

## [0.2.0] - 2026-10-26

- Repackaged the v0.2 prototype as a root-level Unity Package Manager package.
- Added separate Editor and Runtime assembly definitions.
- Moved importer types into the `UnityCoder.ValdradaViewer` namespace.
- Kept Three.js-to-Unity Z conversion and triangle winding fixes from v0.2.
- Retained building shells, ground surfaces, terrain, persistent mesh assets and optional colliders.

## [0.1.0] - 2026-10-26

- Initial prototype importer for Valdrada v0.6.0 CTL1 tiles.
